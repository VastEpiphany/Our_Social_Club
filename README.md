# Our Social Club - 重构版本

🎉 **项目已成功重构完成！**

## 🚀 快速启动

### 方式一：运行主程序（推荐）
```bash
python Main_Login_GUI.py
```

### 方式二：运行新架构版本
```bash
python main.py
```

## 📁 项目结构

```
Our_Social_Club/
├── 📁 src/                    # 重构后的模块化源代码
│   ├── 📁 models/             # 数据模型
│   ├── 📁 views/              # 用户界面
│   ├── 📁 controllers/        # 控制器
│   ├── 📁 services/           # 业务逻辑
│   ├── 📁 components/         # 可复用组件
│   └── 📁 utils/              # 工具函数
├── 📁 assets/                 # 图片资源
├── 📁 data/                   # 数据文件
├── 📁 legacy_backup/          # 原代码备份
├── 📄 Main_Login_GUI.py       # 主程序入口
├── 📄 main.py                 # 新架构入口
└── 📄 requirements.txt        # 项目依赖
```
